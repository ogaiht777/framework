# FiveM ECS Framework

## Overview

This project is an abstract, developer-focused Entity Component System (ECS) framework designed for FiveM. Built with TypeScript, it aims to provide a robust, performant, and flexible foundation for creating diverse game modes and applications within the FiveM environment. Our core philosophy is "Engine-first, content-agnostic," meaning we provide powerful tools and architectural patterns rather than pre-built game features.

## Key Features

*   **ECS Architecture**: Leverages the Entity Component System pattern for highly modular and performant game logic.
*   **Type-Safe Development**: Built entirely in TypeScript for enhanced developer experience, better code quality, and fewer runtime errors.
*   **Core Services**: Includes essential services such as a type-safe event bus, network synchronization, dependency injection, and database abstraction.
*   **Developer Tools**: Features like scaffolding, performance monitoring, and debugging utilities to streamline development.
*   **Security & Optimization**: Incorporates advanced features like spatial partitioning, batch processing, rate limiting, and input sanitization.
