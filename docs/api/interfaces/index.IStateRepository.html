Interface IStateRepository<T, K>

Defines the contract for a state repository. A state repository is the single source of truth for a specific piece of state (e.g., player data). It handles loading state from a persistent source (like a database) and keeping it in memory for fast access.

interface IStateRepository<T, K> {
    delete(key): Promise<void>;
    get(key): null | T;
    load(key): Promise<null | T>;
    save(key): Promise<void>;
    update(key, state): void;
}

Type Parameters

  • T

    The type of the state object.

  • K

    The type of the key used to identify the state (e.g., number for player ID).
